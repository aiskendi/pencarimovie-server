Frequently Asked Questions

How do I install it?

Open Nuvio, then Profile, then Content & Discovery, then Addons, and paste the link. In Stremio, use the Install on Stremio button.

Can I use it only as a stream source?

Yes. Set PencariMovie Catalogs to Disabled. The addon still returns streams for titles you open from another catalog.

What do the catalog controls do?

PencariMovie Catalogs Enabled keeps the local home rows, categories and country rows. Disabled hides them but leaves streams on. Media Types limits which rows are published: Movies, Series and Telegram Files. Core & Telegram Catalogs controls the New, Popular, Search and file rows. Categories & Countries controls the language and genre rows. All and None toggle a whole group.

What do the stream filters and size limits do?

Resolutions, Source Qualities, Encodes & Formats and Exclusions remove rows before the link is built. Block All CAM removes CAM and Telesync. Exclude Unplayable removes known-bad rows. Exclude Part Titles hides files whose names look like split parts. Size and Count Limits cap total streams, streams per resolution, minimum MB and maximum GB. 0 means no cap, minimum or maximum.

Why do sources show but playback fails?

Try another row or stream first. A resolve can be slow, or Telegram can return a flood wait, so retry once and switch to another row. Some files also need a player that supports their format.

Do I need a Telegram account or API keys?

No. The public addon needs no phone number, login code, API ID, API Hash or password. The server uses its own Telegram session and serves the files through its bot.

How do I add content?

Send the file to t.me/INVISObot. It enters the indexing queue.

Should I self-host?

Yes, if you want your own server. The public instance is free and can slow down or go down at any time. Download it from GitHub, run it, then open the dashboard at http://127.0.0.1:8088/ and copy the addon URL from the Addon panel.

Where is the music addon?

Music is a separate manifest at /music/manifest.json. It is hi-res and lossless, and works in Eclipse, LastWave, BitChord and other music clients.
