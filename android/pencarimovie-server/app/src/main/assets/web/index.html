    🚀 How to install in Nuvio:
    1. Connect your Android TV, phone, or tablet to the same Wi-Fi network.
    2. Open the Nuvio app.
    3. Go to profile → content & discovery → addons.
    4. Paste the Wi-Fi / LAN Manifest URL and click Install addon.
