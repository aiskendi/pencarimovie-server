Common questions

What do I install?

Open the install link in Stremio or Nuvio. For Eclipse or BitChord, use the music manifest at /music/manifest.json.

Why does the link change when I change a setting?

Your choices are encoded in the URL. The server does not store an account or a copy of your settings. Re-install the new link after changing something.

Why are some streams missing?

The stream filters can remove rows by resolution, size, codec or language. Set the filters back to Any to see every stream the index has for that title.

Why did a stream stop after it started?

Telegram file references expire. The server refreshes them when it sees the error, so retry once. If the file is HEVC or 10-bit, choose another row when your player cannot decode it.

Do I need a Telegram account?

No. The server reads its own Telegram index and serves the files through its bot. You do not sign in with Telegram.

What is the local server option?

It points the link at a PencariMovie server running on this device. Use it only when that server is running and Stremio or Nuvio is on the same device.

Does public mode include upstream catalogs or subtitles?

No. Public links expose PencariMovie catalogs and Telegram streams only. Upstream Stremio catalogs and subtitle resources are not added to public links.
