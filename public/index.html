      Install steps

      The same address goes into the add-ons screen of every client above.

      How to install:
      1. Make sure the device running the client can reach this server: the same Wi-Fi network, or the public tunnel.
      2. Open Stremio, Nuvio, Streamr, Debrify, WuPlay, Playtario, ARVIO or Cinaura.
      3. Go to that client's add-ons screen and choose to add an add-on by URL.
      4. Paste the address above and confirm. The add-on appears as PencariMovie.
