📖 How to create a Cloudflare Zero Trust Tunnel
  1. Open Cloudflare Dashboard → Zero Trust → Networks → Tunnels (or Tunnel & Mesh).
  2. Click Create a tunnel → Select tunnel type: Cloudflared.
  3. Name your tunnel: e.g. pms → click Save tunnel.
  4. Install and run a connector: Copy the token or connector command (e.g. cloudflared.exe service install eyJh...) and paste it into the box above.
  5. Route tunnel: Add your public hostname:
    • Subdomain / Domain: e.g. addon.yourdomain.com
    • Type: HTTP
    • URL (Service): localhost:8088
